# Djua domain glossary

| Product term | Code term | Meaning |
| --- | --- | --- |
| Dimensionnement | `sizing` | The process of collecting energy needs and recommending a solar system. |
| Devis | `quote` | A commercial proposal produced from a sizing recommendation. |
| Parc solaire | `installations` | The set of installed or active customer solar systems. |
| Intervention | `intervention` | A technician visit associated with an installation. |
| Shop | `shop` | An Orange Énergie distributor or sales point. |
| Commercial | `salesRepresentative` | A sales representative associated with a shop. |

Use the code term consistently. Do not introduce synonyms such as `proposal`, `estimate`, or `quotation` for `quote`.
